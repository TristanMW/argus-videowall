Features

A serious wall, without the NVR baggage

Argus was built to fix a real gap: vendor NVR software won't put arbitrary RTSP devices — like a door intercom — on the same screen as your cameras. Argus puts anything with an RTSP URL on one low-latency grid, and stays deliberately simple: live monitoring only.

Managed from the browser

Add, edit and remove cameras on a config page. Changes apply live — no restarts, no YAML, no file editing.

Sub-second video

WebRTC streaming with no transcoding: ~0.2 s latency and tiny CPU use, with an automatic MSE fallback.

Any RTSP source

Dahua, Hikvision, UniFi, Amcrest, Reolink, Axis — and non-cameras like a Fanvil door intercom. If it has an RTSP URL, it's a tile.

Two-way talk

Answer the door from the wall: push-to-talk sends your microphone to intercoms that support back-channel audio.

Audio, per tile

Listen on any camera with one click, mute everything at once, and go fullscreen per tile or for the whole wall.

Installs as an app

A real PWA: install it from the browser, launch it like a native app, and the shell even opens offline.

Finds itself on the LAN

The box advertises argus.local via mDNS; other devices attach with one click on “Detect on network”.

Self-healing

Streams reconnect automatically; on Windows a silent boot task supervises the engine and restarts it if anything dies.

How it works

One small box does everything

Argus runs on any spare machine on your network — a desktop, a mini-PC, a NAS. Two lightweight processes, no database, no GPU needed.

1

The engine pulls each camera once

The battle-tested go2rtc engine connects to every RTSP source a single time — your cameras never get hammered by multiple viewers.

2

Re-served as WebRTC, untouched

Streams are repackaged (not transcoded) into WebRTC for every browser watching. That's why latency is ~0.2 s and CPU use stays tiny.

3

A zero-dependency backend runs the show

A small Node service serves the wall, owns the camera list and pushes changes into the engine live. Saved config survives reboots.

Install

Running in about two minutes

Grab the code from GitHub, then pick your platform. Both paths are fully scripted.

Recommended · Windows

Windows — no Docker

For client PCs and mini-PCs. No virtualization, no WSL2, no Docker licence.

  • Installs Node.js and the streaming engine automatically
  • Opens the firewall for LAN viewing
  • Starts silently at every boot — no login, no windows
  • Ships with a one-click, complete uninstaller
# in the Argus folder — accept the admin prompt
setup-windows.bat

# remove every trace later
uninstall-windows.bat

Docker — any OS

One command on anything that runs Docker: Windows, macOS, Linux, NAS.

  • Two containers: the engine + the Argus backend
  • Camera list persists in a named volume
  • Installer scripts set Docker up if it's missing
# Windows
powershell -ExecutionPolicy Bypass -File .\install.ps1
# macOS / Linux
./install.sh
# or, with Docker already installed:
docker compose up -d --build

Then: add cameras

Everything else happens in the browser.

  • Open http://localhost:8080 on the box
  • Go to Add cameras, paste each RTSP URL, Save & apply
  • On other devices, open the wall and hit Detect on network
  • Optionally install it as an app (PWA) and go fullscreen
# typical camera URLs
rtsp://user:pass@192.168.1.64:554/…   # Dahua / Hikvision
rtsp://192.168.1.90/live/av0          # Fanvil intercom

Privacy & security

Your cameras are nobody's business

Camera systems are exactly the thing you shouldn't hand to a cloud. Argus is architected so there's nothing to trust: video, camera config and processing never leave hardware you own.

  • ✓100% local processing. RTSP ingest, streaming and configuration all run on your box. No video frame ever leaves your network.
  • ✓No accounts, no telemetry, no third-party scripts. The UI bundles zero CDNs, trackers or analytics — it only ever talks to your own box.
  • ✓No recording, by design. Argus is a live monitor. There is no footage archive to leak, subpoena or fill a disk with.
  • ✓Private remote access done right. Watch from anywhere over Tailscale — a WireGuard-encrypted private mesh with valid HTTPS — instead of port-forwarding cameras to the internet.
  • ✓Fully auditable. The code running on your box is plain, readable JavaScript — you can inspect every line of what touches your cameras. Even license keys are verified locally, offline.
FAQ

Questions, answered

Does Argus record footage?

No — deliberately. Argus is a pure live wall: watch, listen, talk. If you need recording, motion detection or AI events, run a recorder like Frigate or your NVR alongside it; Argus happily displays the same cameras.

Which cameras work?

Anything that exposes an RTSP stream — which is nearly every IP camera made in the last decade: Dahua, Hikvision, UniFi Protect, Amcrest, Reolink, Axis, TP-Link and more, plus SIP/RTSP door intercoms like Fanvil. If VLC can open the URL, Argus can wall it.

Do I need Docker?

No. On Windows the recommended path is the native installer (setup-windows.bat) — no virtualization or WSL2 required, and it auto-starts silently at boot. Docker remains a one-command option on any OS if you prefer containers.

Can I watch when I'm away from home?

Yes — privately. Install Tailscale on the box and your phone, run the bundled serve script, and the wall is available over HTTPS to your devices only. Nothing is port-forwarded and nothing is reachable from the public internet.

What hardware do I need?

Very little. Because streams are repackaged rather than transcoded, a modest mini-PC or an old desktop handles a full 4×4 wall. No GPU needed. The viewing side is just a browser — a wall-mounted TV with a stick PC works great.

What does it cost?

Two cameras are free forever, with every feature included. From the third camera onwards it's $2 per camera per month, paid by PayPal subscription — you get a license key by email and paste it into Argus once. The key is verified on your own box, offline; there's still no cloud account and no telemetry. Cancel anytime and the wall simply falls back to the two free cameras.
